# Malek Bsaissa — Portfolio

Personal portfolio for **Malek Bsaissa**, a cloud engineering student at ESPRIT (ARCTIC section). Built with Next.js 16, TypeScript, and Tailwind CSS.

**[malekbsaissa.vercel.app](https://malekbsaissa.vercel.app/)**

## Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Phosphor
- **Deployment**: Vercel

## Features

- Radial entrance animation
- Dark/light theme toggle with radial transition
- Cursor-following accent glow
- Spotlight text effect on headings
- GitHub contribution heatmap
- Interactive timeline
- Scroll spy navigation
- Responsive, minimal editorial design

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to `main` — Vercel auto-deploys.
